# 42COG 认知敏捷法

项目的认知框架目录，用于组织项目的核心认知资产。

## 文件说明

| 文件 | 说明 |
|------|------|
| `cog.md` | 认知模型 — 定义核心实体及关系 |
| `meta.md` | 项目元信息 — 名称、版本、技术栈等 |
| `real.md` | 现实约束 — 必须遵守的硬性限制 |
| `user/` | 用户角色规约 — 用户与管理员视角 |
| `pm/` | 产品经理规约 — 需求文档与用户故事 |
| `dev/` | 开发规约 — 架构、数据库、编码、测试、运维 |
| `design/` | 设计规约 — 交互设计与平面设计 |

## RCS 工作流

```
Real (现实约束) → Cog (认知模型) → Spec (角色规约) → Work（实际作品） 
```
