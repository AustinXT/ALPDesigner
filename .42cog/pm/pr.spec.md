## 1. 产品环境

**名称：** 铝型材设计师 (ALPDesigner)
**标语：** 一个可以用自然语言描述想法、即时获得可加工铝型材 CAD 方案的环境
**环境描述：** 用户进入一个对话式设计空间，将脑中模糊的结构想法转化为精确的铝型材 CAD 方案。无需 CAD 专业知识，AI 理解意图并生成可直接下单加工的完整方案。用户可在 3D 空间中查看、调整和验证设计，最终导出材料清单和组装指导。
**主要智能体：** 见 cog.md §1（设计用户 A1、设计助手 A2、CAD 渲染引擎 A3）
**核心可供性：**
1. 自然语言/图片 → 3D 结构方案（描述即设计）
2. 3D 空间中的可视化编辑（看到即可改）
3. 一键导出可加工的完整方案（设计即落地）

## 2. 最小可供故事

### MAS-1：描述想法，看到方案

**故事主题：** 用户将脑中的结构想法转化为可见的 3D 铝型材方案

**可供性序列：**
1. **描述输入**：用自然语言描述需求（感知：输入框 placeholder 示例 + 场景模板按钮）
2. **图片辅助**：上传参考图片补充描述（感知：拖拽区域 + 图片预览）
3. **方案生成**：AI 解析意图，流式输出 CAD 参数（感知：生成进度指示 + 3D 模型逐步构建动画）
4. **3D 预览**：在三维空间中旋转、缩放查看方案（感知：可交互的 3D 视口）
5. **材料清单**：查看型材、连接件、板材明细（感知：侧边栏 BOM 面板）
6. **快速导出**：导出 BOM 为 CSV（感知：导出按钮）

**意义闭合：** 用户从"我想做一个……"变成"原来需要这些材料，看起来是这样的"
**内在动机：** 即时可见的 3D 方案带来的掌控感和可行感——"我真的可以做出来"
**依赖：** 无前置 / 启用 MAS-2、MAS-3
**超出范围：** Web 编辑器中的手动拖拽调整、结构安全分析报告、组装指导 PDF

### MAS-2：调整设计，验证安全

**故事主题：** 用户在 AI 生成的方案基础上精调细节，并确认结构安全可靠

**可供性序列：**
1. **选择元素**：点击 3D 模型中的型材或连接件（感知：高亮选中 + 属性面板弹出）
2. **参数调整**：修改尺寸、型材系列、连接方式（感知：属性面板输入框 + 实时预览更新）
3. **拖拽移动**：在 3D 空间中拖拽元素重新定位（感知：拖拽手柄 + 对齐辅助线）
4. **连接检测**：系统自动检测接近的元素并建议连接方式（感知：虚线连接提示 + 连接件推荐弹窗）
5. **兼容性校验**：实时提示型材与连接件的兼容性问题（感知：冲突元素红色标记 + 警告文字）
6. **结构验证**：触发结构安全检查，查看承载力和稳定性评估（感知：安全评分徽章 + 详细报告面板）

**意义闭合：** 用户从"AI 给的方案大致对"变成"每个细节我都确认过了，结构安全"
**内在动机：** 精通感——理解了结构原理，亲手优化了方案
**依赖：** 需要 MAS-1 / 启用 MAS-3
**超出范围：** 自由建模（从空白开始画）、有限元分析、多方案对比

### MAS-3：导出方案，动手组装

**故事主题：** 用户将验证过的设计转化为可直接下单加工并按步骤组装的完整产出物

**可供性序列：**
1. **加工参数导出**：生成含切割长度、钻孔位置、攻丝规格的加工单（感知：导出菜单 → "加工参数" 选项）
2. **STEP 文件导出**：导出标准 CAD 交换格式（感知：导出菜单 → "STEP" 选项）
3. **组装指导生成**：AI 生成带图解的分步组装步骤（感知：导出菜单 → "组装指导 PDF"）
4. **效果图渲染**：生成静态渲染效果图（感知：导出菜单 → "效果图"）
5. **成本估算**：显示材料成本参考范围（感知：BOM 面板底部的价格汇总区域）
6. **运输提醒**：超长型材自动标注并提示运输方式选择（感知：BOM 中的运输标记图标）

**意义闭合：** 用户从"设计完成了"变成"材料已下单，周末就能动手组装"
**内在动机：** 自主感——完全掌握从设计到制造的全流程
**依赖：** 需要 MAS-1 + MAS-2
**超出范围：** 在线下单购买材料、自动联系加工厂、实时价格查询

### 项目特有约束

- **无后端存储**：所有设计数据仅存在于浏览器 localStorage/IndexedDB（见 cog.md §3.1）。用户切换设备或清除浏览器数据将丢失设计方案，需在 UI 中明确提示
- **匿名使用**：无需注册登录。会话标识基于 sessionStorage（见 cog.md §1.1 A1），跨浏览器不共享
- **AI 输出格式**：Claude API 流式输出 CAD 参数 JSON，必须符合 cog.md §2.1 中定义的实体 Schema。AI 不直接生成几何体，仅生成参数，由 CAD 引擎渲染
- **场景分级**：工业场景（流水线/货架）的安全验证标准必须高于家用 DIY 场景，需要用户在输入时标明用途场景（见 cog.md §1.1 A1 分类）

## 5. 验收标准

| ID | 标准 | 验证方式 |
|----|------|----------|
| AC-01 | 用户输入自然语言描述后 ≤30s 内开始看到 3D 模型构建 | 输入"帮我设计一个 600×400×1500mm 的书架"，计时从提交到首个 3D 元素出现 |
| AC-02 | AI 生成的 BOM 中型材与连接件 100% 系列匹配 | 批量测试 20 个不同描述，检查每个方案的 BOM 兼容性 |
| AC-03 | 加工参数导出精度达到 0.5mm 且扣除连接件占位 | 导出一个包含角码连接的方案，验证切割长度 = 设计长度 - 角码厚度 |
| AC-04 | 结构验证能拦截明显不安全的设计（如 2020 型材 2m 无支撑跨距承重 50kg） | 构造 5 个已知不安全的设计方案，验证全部被标记为"不通过" |
| AC-05 | 3D 预览在 WASM 加载完成后交互帧率 ≥30fps（200 个元素以内） | 创建包含 200 个设计元素的方案，Chrome DevTools 检查帧率 |
| AC-06 | WASM 通过 Web Worker 加载，不阻塞主线程 | Chrome Performance 录制加载过程，确认主线程无 >100ms 的 long task |
| AC-07 | 连接点自动检测覆盖直角、T 形、端面三种基本接合 | 构建包含三种接合的结构，验证系统全部自动检测到并推荐连接件 |
| AC-08 | 用户清除浏览器数据前收到数据丢失风险提示 | UI 中存在明确的数据持久化说明文字 |
| AC-09 | 混用不同系列型材时系统提示需要转接件 | 创建包含 2020 和 4040 混用的方案，验证接合处提示兼容性问题 |

## 6. 非可供性（明确禁止的行动及理由）

| 禁止的行动 | 理由 |
|-----------|------|
| 自由建模（从空白开始绘制任意几何形状） | 本产品聚焦铝型材参数化设计，非通用 CAD 软件。自由建模极大增加复杂度且偏离核心价值 |
| 在线下单购买材料 | 涉及供应链对接、支付系统、库存管理，超出 MVP 和产品定位范围 |
| 有限元分析（FEA） | 精确 FEA 需要专业输入参数和计算资源，基本结构安全检查已满足目标用户需求 |
| 多人协作编辑 | 无后端存储，数据在浏览器本地，不支持多人实时协作。超出当前产品定位 |
| 存储用户原始图片到服务端 | 见 real.md §C4——隐私约束，仅前端压缩传输用于 AI 理解，不持久化 |
| 绕过结构验证直接导出加工参数 | 见 real.md §C1——未经验证的方案可能导致结构失稳，不得供用户直接加工 |

## 7. 技术实现要点

以下仅列出 pr.spec 层面需要明确的技术决策点，架构细节由 sys.spec 承载。

- **AI 输出协议**：Claude API 以 streaming JSON 输出 CAD 参数，前端逐步解析并驱动 3D 渲染。需要定义 JSON Schema 作为 AI 和 CAD 引擎间的契约（schema 内容由 sys.spec 定义，pr.spec 仅要求其存在）
- **型材参数库**：内置标准铝型材参数库（2020~8080 系列），数据格式为 JSON，随应用发布。参数库需覆盖 cog.md §2.1 E1 定义的全部属性
- **连接件参数库**：内置连接件参数库，包含兼容性映射关系。需覆盖 cog.md §2.1 E2 定义的全部类型和属性
- **结构安全检查器**：基于型材惯性矩、跨距、负载的简化力学计算（非 FEA），规则引擎实现。工业和家用场景使用不同安全系数
- **渐进式加载**：WASM 模块按需加载，首屏仅加载对话界面，用户首次触发 3D 预览时才加载 CAD 引擎
