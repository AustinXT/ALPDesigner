## CS-01: 从描述到方案

**描述：** 用户将脑中模糊的铝型材结构想法，通过自然语言和图片输入，转化为可见的 3D 方案和材料清单
**用户类型：** 设计用户（见 cog.md §1.1 A1）
**核心价值：** 零 CAD 知识门槛，从"我想做一个……"到"原来需要这些材料"
**类型分布：** 光明 3 / 黑暗 1 / 灰色 1
**包含故事：** MS-L-01, MS-L-02, MS-L-03, MS-D-01, MS-G-01
**旅程：** 输入描述 → AI 生成方案 → 3D 预览呈现 → 查看 BOM → 迭代优化

---

### MS-L-01：首次描述生成 3D 方案

**所属**：CS-01 | **类型**：光明 | **优先级**：P0

**用户故事**：
作为设计用户，我想要用自然语言描述我需要的结构，以便在不懂 CAD 的情况下看到铝型材 3D 方案

**故事评判**：
- 起点：脑中有模糊想法但不知如何转化为铝型材结构
- 转折：输入描述后 AI 理解意图并流式生成 CAD 参数
- 终点：3D 视口中出现可旋转查看的铝型材结构模型

**用户可感知变化**：
- 操作前：空白的 3D 视口 + 带引导 placeholder 的输入框
- 操作中：输入描述后看到生成进度指示，3D 模型逐步构建
- 操作后：完整的 3D 铝型材结构可旋转、缩放查看

**验收标准**：
- [ ] 输入描述后 ≤30s 内首个 3D 元素出现（见 pr.spec.md AC-01）
- [ ] 生成的方案包含型材、连接件的完整参数 JSON
- [ ] 场景模板按钮（书架/工作台/货架等）可一键填入描述

**约束**：见 real.md §C4（WASM Worker 加载）
**依赖**：无前置 / 使能 MS-L-03, MS-D-01, MS-G-01

---

### MS-L-02：图片辅助描述意图

**所属**：CS-01 | **类型**：光明 | **优先级**：P1

**用户故事**：
作为设计用户，我想要上传参考图片补充我的文字描述，以便 AI 更准确理解我想要的结构样式

**故事评判**：
- 起点：文字描述不够精确，不确定 AI 能否理解我想要的结构外观
- 转折：上传一张参考图片，AI 结合图片和文字理解意图
- 终点：生成的方案更贴近预期，减少后续修改次数

**用户可感知变化**：
- 操作前：仅有文字输入框
- 操作中：拖拽或点击上传图片，看到预览缩略图
- 操作后：AI 生成的方案参考了图片中的结构特征

**验收标准**：
- [ ] 支持拖拽和点击两种上传方式
- [ ] 图片在前端压缩后传输，上传过程中显示预览缩略图
- [ ] 支持多图上传

**约束**：见 real.md §C4（前端压缩，不存储原图）
**依赖**：与 MS-L-01 互补 / 使能 MS-L-01 精度提升

### MS-L-03：查看材料清单

**所属**：CS-01 | **类型**：光明 | **优先级**：P0

**用户故事**：
作为设计用户，我想要查看方案的完整材料清单，以便知道需要采购哪些型材和连接件

**故事评判**：
- 起点：看到了 3D 模型但不知道具体需要哪些材料和数量
- 转折：侧边栏展示按类别分组的 BOM 清单
- 终点：清楚知道每种型材的型号、长度、数量和所需连接件

**用户可感知变化**：
- 操作前：只有 3D 预览，不知道具体物料
- 操作中：打开侧边栏 BOM 面板，按型材/连接件/板材分类浏览
- 操作后：点击 BOM 条目时 3D 视口高亮对应元素，建立空间—清单映射

**验收标准**：
- [ ] BOM 按型材、连接件、板材三类分组展示
- [ ] 点击 BOM 条目 → 3D 视口高亮对应元素
- [ ] 支持 BOM 导出为 CSV

**约束**：见 real.md §C2（型材与连接件兼容性）
**依赖**：需要 MS-L-01 / 使能 CS-03

### MS-D-01：AI 生成方案偏离意图

**所属**：CS-01 | **类型**：黑暗 | **优先级**：P1

**用户故事**：
作为设计用户，当 AI 生成的方案不符合我的预期时，我想要能快速理解偏差并纠正，以便不至于从头重来

**故事评判**：
- 起点：AI 已生成一个方案，看起来还不错
- 转折：仔细查看后发现尺寸、结构或型材选择与预期不符
- 终点：通过对话或直接修改参数纠正偏差，无需重新描述

**用户可感知变化**：
- 操作前：生成的方案在 3D 视口中展示
- 操作中：发现问题后在对话区输入修改指令（如"高度改成 1.5m"）
- 操作后：方案局部更新，修改部分高亮闪烁，diff 可见

**验收标准**：
- [ ] 对话式修改后仅更新受影响的部分，非全量重新生成
- [ ] 修改后的元素高亮闪烁提示变化位置
- [ ] 每次修改后自动触发兼容性校验

**约束**：见 real.md §C2（修改后重新校验兼容性）
**依赖**：需要 MS-L-01 / 使能 MS-G-01

### MS-G-01：对话式迭代优化方案

**所属**：CS-01 | **类型**：灰色 | **优先级**：P1

**用户故事**：
作为设计用户，我想要通过多轮对话逐步完善方案，以便在不确定最终需求时渐进式探索最佳设计

**故事评判**：
- 循环模式：描述 → 查看 → 修改 → 查看 → 再修改，多轮往复
- 优化点：每轮修改的反馈时间足够短，不打断思考流
- 习惯形成：从"不确定想要什么"到"边看边想，越来越清晰"

**用户可感知变化**：
- 操作前：初始方案与最终需求有差距
- 操作中：多次输入修改指令，每次看到局部更新
- 操作后：方案经过多轮迭代逐渐逼近理想设计

**验收标准**：
- [ ] 支持连续多轮对话修改，上下文不丢失
- [ ] 每轮修改响应时间 ≤10s
- [ ] 对话历史可回溯，可撤销到之前的版本

**约束**：无额外约束
**依赖**：需要 MS-L-01 + MS-D-01

## CS-02: 精调与验证

**描述：** 用户在 AI 生成的方案基础上，通过可视化编辑器精调每个细节，并通过结构安全检查确认方案可靠
**用户类型：** 设计用户（见 cog.md §1.1 A1，by-intent: 完整设计）
**核心价值：** 从"AI 给的大致对"到"每个细节我都确认过，结构安全"
**类型分布：** 光明 3 / 黑暗 2 / 灰色 1
**包含故事：** MS-L-04, MS-L-05, MS-L-06, MS-D-02, MS-D-03, MS-G-02
**旅程：** 选中元素 → 调整参数 → 拖拽布局 → 连接检测 → 兼容性校验 → 结构验证通过

---

### MS-L-04：选中元素调整参数

**所属**：CS-02 | **类型**：光明 | **优先级**：P1

**用户故事**：
作为设计用户，我想要点击 3D 模型中的元素并修改其参数，以便精确控制每根型材的规格和尺寸

**故事评判**：
- 起点：AI 生成的方案中某根型材规格不理想
- 转折：点击该型材，属性面板弹出，可直接修改系列/长度/表面处理
- 终点：修改即时反映在 3D 预览中，参数精确可控

**用户可感知变化**：
- 操作前：型材以默认参数显示在 3D 视口
- 操作中：点击后元素高亮，侧边属性面板显示可编辑参数
- 操作后：修改参数后 3D 模型实时更新，BOM 同步变化

**验收标准**：
- [ ] 点击元素后高亮选中并弹出属性面板
- [ ] 可修改型材系列、长度、表面处理等参数
- [ ] 参数修改后 3D 模型和 BOM 实时同步更新

**约束**：见 real.md §C2（修改型材系列时校验连接件兼容性）
**依赖**：需要 CS-01 / 使能 MS-D-02, MS-G-02

---

### MS-L-05：拖拽元素重新布局

**所属**：CS-02 | **类型**：光明 | **优先级**：P1

**用户故事**：
作为设计用户，我想要在 3D 空间中拖拽型材重新定位，以便调整结构布局而不用修改数值参数

**故事评判**：
- 起点：某根型材的位置不理想，想移动到另一个位置
- 转折：通过拖拽手柄在 3D 空间中移动元素，辅助线帮助对齐
- 终点：元素移动到新位置，连接关系自动更新

**用户可感知变化**：
- 操作前：元素在原位置
- 操作中：拖拽时显示对齐辅助线和吸附网格
- 操作后：元素在新位置，附近的连接点自动重新检测

**验收标准**：
- [ ] 选中元素后出现拖拽手柄（X/Y/Z 轴）
- [ ] 拖拽时显示对齐辅助线，支持吸附到网格
- [ ] 移动后自动重新检测附近连接点

**约束**：无额外约束
**依赖**：需要 MS-L-04 / 使能 MS-L-06

---

### MS-L-06：连接点自动检测与推荐

**所属**：CS-02 | **类型**：光明 | **优先级**：P1

**用户故事**：
作为设计用户，我想要系统自动检测型材间的接合关系并推荐连接件，以便不需要查阅连接件手册就能完成装配设计

**故事评判**：
- 起点：多根型材已布置到位，但连接方式未确定
- 转折：系统自动识别接合几何，虚线提示连接关系，弹窗推荐连接件
- 终点：确认连接件选择后，设计方案的连接关系完整

**用户可感知变化**：
- 操作前：型材间无连接件，只是空间上接近
- 操作中：接近的型材间出现虚线连接提示和连接件图标
- 操作后：点击确认后连接件添加到方案中，BOM 自动更新

**验收标准**：
- [ ] 覆盖直角、T 形、端面三种基本接合几何（见 pr.spec.md AC-07）
- [ ] 推荐的连接件与型材系列兼容
- [ ] 支持手动更换推荐的连接件类型

**约束**：见 real.md §C2（连接件必须匹配型材系列）
**依赖**：需要 MS-L-05 / 使能 MS-D-02

---

### MS-D-02：型材与连接件兼容性冲突

**所属**：CS-02 | **类型**：黑暗 | **优先级**：P0

**用户故事**：
作为设计用户，当我混用不同系列型材或选错连接件时，我想要系统立即警告并给出替换建议，以便避免购买无法组装的材料

**故事评判**：
- 起点：方案中型材和连接件搭配正常
- 转折：修改某根型材为不同系列后，与现有连接件不兼容
- 终点：系统标红冲突元素，提示不兼容原因并推荐替换方案

**用户可感知变化**：
- 操作前：方案正常，无警告
- 操作中：修改型材系列后冲突元素出现红色边框 + 警告 tooltip
- 操作后：选择推荐的替换方案后冲突解除，恢复正常

**验收标准**：
- [ ] 混用不同系列型材时在接合处提示兼容性问题（见 pr.spec.md AC-09）
- [ ] 冲突元素红色边框 + 警告文字说明不兼容原因
- [ ] 提供兼容的替换连接件建议
- [ ] AI 生成的 BOM 中型材与连接件 100% 系列匹配（见 pr.spec.md AC-02）

**约束**：见 real.md §C2
**依赖**：需要 MS-L-04 或 MS-L-06 / 使能 MS-D-03

---

### MS-D-03：结构安全检查不通过

**所属**：CS-02 | **类型**：黑暗 | **优先级**：P0

**用户故事**：
作为设计用户，当我的设计存在结构安全隐患时，我想要系统明确指出问题位置和原因，以便在下单加工前修正设计

**故事评判**：
- 起点：方案设计完成，准备导出加工参数
- 转折：结构验证发现承载力不足/跨距超限/连接点不够等问题
- 终点：定位到具体问题元素，给出加粗型材/增加支撑/补充连接件等修改建议

**用户可感知变化**：
- 操作前：方案状态为"草稿"
- 操作中：触发验证后安全评分徽章显示"警告"或"不通过"，问题元素高亮
- 操作后：按建议修改后重新验证，评分变为"通过"，方案状态升为"已验证"

**验收标准**：
- [ ] 能拦截明显不安全设计——如 2020 型材 2m 无支撑跨距承重 50kg（见 pr.spec.md AC-04）
- [ ] 工业场景（流水线/货架）使用更严格的安全系数
- [ ] 点击警告项定位到具体元素并给出修改建议
- [ ] 方案必须通过验证才能导出加工参数

**约束**：见 real.md §C1（不得输出未经验证的方案供用户加工）
**依赖**：需要 MS-D-02（兼容性无冲突）/ 使能 CS-03

### MS-G-02：反复调参直到满意

**所属**：CS-02 | **类型**：灰色 | **优先级**：P2

**用户故事**：
作为设计用户，我想要在编辑和验证之间快速循环，以便高效找到满足安全和功能需求的最优方案

**故事评判**：
- 循环模式：调整参数 → 查看 3D 效果 → 触发验证 → 查看结果 → 再调整
- 优化点：编辑到验证的反馈闭环足够短，支持撤销/重做
- 习惯形成：从逐个尝试到建立"型材系列—承载—场景"的直觉映射

**用户可感知变化**：
- 操作前：方案有若干警告项未解决
- 操作中：多轮调整参数并重新验证，每轮看到警告项减少
- 操作后：所有警告清除，安全评分为"通过"

**验收标准**：
- [ ] 支持撤销/重做操作（Ctrl+Z / Ctrl+Shift+Z）
- [ ] 编辑后重新验证响应时间 ≤5s
- [ ] 验证结果实时反映参数变化，无需手动刷新

**约束**：无额外约束
**依赖**：需要 MS-L-04 + MS-D-03

## CS-03: 导出与落地

**描述：** 用户将验证通过的设计方案转化为可直接下单加工和按步骤组装的完整产出物
**用户类型：** 设计用户（见 cog.md §1.1 A1，by-intent: 完整设计）
**核心价值：** 从"设计完成了"到"材料已下单，周末就能动手组装"
**类型分布：** 光明 2 / 黑暗 2 / 灰色 1
**包含故事：** MS-L-07, MS-L-08, MS-D-04, MS-D-05, MS-G-03
**旅程：** 选择导出格式 → 生成加工参数 → 生成组装指导 → 检查成本和运输 → 下载全部文件

---

### MS-L-07：导出完整加工参数

**所属**：CS-03 | **类型**：光明 | **优先级**：P0

**用户故事**：
作为设计用户，我想要导出可直接发给工厂的加工参数单，以便下单切割和加工铝型材

**故事评判**：
- 起点：设计方案已通过结构验证，但不知道如何转化为加工订单
- 转折：一键导出包含切割长度、钻孔位置、攻丝规格的完整加工单
- 终点：拿到精确的加工参数 CSV/PDF，可直接发送给铝型材工厂

**用户可感知变化**：
- 操作前：已验证的 3D 方案，无加工文件
- 操作中：点击导出菜单 → 选择"加工参数"→ 生成并下载
- 操作后：获得包含每根型材切割长度（已扣除连接件占位）、钻孔和攻丝要求的文件

**验收标准**：
- [ ] 切割长度精度 0.5mm，已扣除连接件占位（见 pr.spec.md AC-03）
- [ ] 所有尺寸标注公差范围
- [ ] 导出格式支持 CSV
- [ ] 仅已通过验证的方案可导出加工参数

**约束**：见 real.md §C3（加工参数精度）、§C1（必须验证后才能导出）
**依赖**：需要 CS-02（方案已验证）/ 使能用户下单加工

---

### MS-L-08：生成分步组装指导

**所属**：CS-03 | **类型**：光明 | **优先级**：P1

**用户故事**：
作为设计用户，我想要获得带图解的分步组装指导，以便收到材料后按步骤完成组装

**故事评判**：
- 起点：材料已切割加工完毕，摆在面前不知从何下手
- 转折：AI 生成按顺序排列的组装步骤，每步包含图解和所需工具
- 终点：按步骤逐一组装，无需额外求助

**用户可感知变化**：
- 操作前：有加工参数但无组装说明
- 操作中：点击导出"组装指导 PDF"→ AI 生成分步指导
- 操作后：获得包含装配顺序、每步用到的连接件和工具、关键注意事项的 PDF

**验收标准**：
- [ ] 组装步骤按合理的装配顺序排列（先主框架后附件）
- [ ] 每步标注所需连接件型号和数量
- [ ] 导出为 PDF 格式

**约束**：无额外约束

### MS-D-05：成本超出预期

**所属**：CS-03 | **类型**：黑暗 | **优先级**：P2

**用户故事**：
作为设计用户，当方案材料成本明显偏高时，我想要收到优化建议，以便在功能和成本之间取得平衡

**故事评判**：
- 起点：方案已验证，准备下单
- 转折：BOM 底部显示材料成本估算，发现存在更经济的替代方案
- 终点：采纳优化建议（如换用更小系列型材、减少连接件）后成本降低

**用户可感知变化**：
- 操作前：BOM 面板仅显示物料列表
- 操作中：BOM 底部出现价格汇总区域，标注"参考价，不含加工费和运费"
- 操作后：存在更经济方案时显示优化提示，采纳后成本和方案同步更新

**验收标准**：
- [ ] 基于型材重量和连接件数量估算材料成本范围
- [ ] 存在更经济的替代型材系列或连接方式时主动提示
- [ ] 成本估算明确标注不含加工费和运费

**约束**：见 real.md §C7
**依赖**：需要 MS-L-03

### MS-G-03：多次调整后重新导出

**所属**：CS-03 | **类型**：灰色 | **优先级**：P2

**用户故事**：
作为设计用户，我想要在调整方案后快速重新导出所有文件，以便每次修改后都能拿到最新的加工参数

**故事评判**：
- 循环模式：导出 → 发现问题 → 返回编辑 → 重新导出
- 优化点：重新导出不需要重复配置导出选项
- 习惯形成：从"担心改了没更新"到"随时导出都是最新的"

**用户可感知变化**：
- 操作前：上次导出的文件已过时
- 操作中：修改方案后一键重新导出
- 操作后：获得与当前方案完全一致的最新导出文件

**验收标准**：
- [ ] 方案修改后导出文件自动标记为"过时"
- [ ] 重新导出保留上次的导出配置
- [ ] 导出文件包含方案版本标识，避免混淆

**约束**：见 real.md §C1（修改后需重新验证）
**依赖**：需要 MS-L-07 + CS-02
