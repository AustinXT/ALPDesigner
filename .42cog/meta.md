# 项目元信息 (Meta)

## 基本信息

- **项目名称**：铝型材设计师 (ALPDesigner)
- **项目标语**：描述你的想法，生成铝型材 CAD 方案，在家动手组装
- **版本**：0.1.0
- **创建日期**：2026-03-15
- **负责人**：nv

## 项目描述

ALPDesigner 是一个基于 Web 的铝型材结构设计工具。用户通过自然语言描述或上传图片，AI 自动生成铝型材框架的 CAD 设计，包含完整的材料清单、加工参数和组装指导。覆盖从工业场景（流水线、货架、设备防护罩）到个人 DIY（书架、工作台）的全场景铝型材结构设计需求。

## 目标用户

- **工厂/车间**：用铝型材组装流水线框架、货架、设备防护罩、工作台、物料架等工业结构
- **DIY 爱好者**：搭建书架、工作台、3D 打印机框架等家用结构
- **小型工作室**：定制展架、设备支架、陈列柜等商业结构
- **创客/教育**：教学场景下的结构设计与动手实践

## 技术栈

- **前端**：Next.js 16 + React + TypeScript
- **3D 渲染**：react-three-fiber + @react-three/drei
- **CAD 内核**：replicad（OpenCascade WASM）
- **AI**：Claude API（自然语言 → CAD 参数）
- **运行时**：Bun
- **部署**：Vercel
